
# PLP -python Week 3 Assignment

This assignment practices loops, conditions, counting, and debugging in Python.

## Files

- `grade_reporter.py`: Assigns grades to scores, counts passes and failures, and calculates the average.
- `bug_hunt.py`: Demonstrates how to identify and fix three bugs in a while-loop program.

## Reflection

The hardest bug to find was the incorrect loop condition because the program could run without an error message but still produce the wrong answer. I knew something was wrong because the program was supposed to add the numbers from 1 to 5 and produce 15, but the incorrect condition stopped the loop before it included 5.
